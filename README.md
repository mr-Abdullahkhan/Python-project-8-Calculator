🧮 Calculator (Python)
===

This is a simple Python command-line calculator that performs basic arithmetic operations such as addition, subtraction, multiplication, and division. The program allows continuous calculations until the user chooses to start a new one.

---
**📌 Project Description**

The calculator takes two numbers and an operation from the user and displays the result.
After each calculation, the user can choose to continue calculating with the current result or start a new calculation.

This project helped me understand functions, dictionaries, loops, and how to build reusable logic in Python.

___
**🛠️ Technologies Used**

* Python 3
* Command Line / Terminal
* Functions
* Dictionary data structure
* Custom ASCII art logo

___
**▶️ How It Works**

1. The program displays a calculator logo
2. The user enters the first number
3. The user selects an operation (+, -, *, /)
4. The user enters the next number
5. The result is displayed
6. The user can continue with the result or start a new calculation

___
**🧮 Example Usage**

    What is the first number?: 10
    +
    -
    *
    /
    Pick an operation: *
    What is the next number?: 5
    10 * 5 = 50
    
    Type 'y' to continue calculating with 50, or type 'n' to start a new calculation:
